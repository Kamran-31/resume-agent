# AI Resume Review Agent (CrewAI + Streamlit + Groq)

A single-agent recruitment audit application that benchmarks candidate resumes against job descriptions without inventing details or hallucinating qualifications.

## Features
- **Strict Evidence Mandate**: Only claims requirements are met when explicitly documented.
- **Dual Input Modes**: Supports PDF upload extraction (`pypdf`) or direct text pasting.
- **High-Speed Inference**: Powered by Groq models via CrewAI's `LLM` integration.
- **Modern UI**: Styled with Emerald Green, Deep Violet, and Amber accents.
- **Zero Permanent Storage**: Runs ephemerally in session memory.
